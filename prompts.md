# Song Prompts – Ideas

A song prompt/cue generator inspired by Brian Eno & Peter Schmidt's *Oblique Strategies* — but more concrete and aimed at people making music in a DAW. Each card is a **category + a cue**. Draw one, or draw one from several categories and combine them.

Format: `Category: Cue`. Original seed ideas are marked ★.

**This file is the app's cue list.** Each `## Heading` becomes a category in the app, and each `- Label: Cue` line under it becomes a card. Lines in any other format are ignored. These placeholders are filled with a random value on every draw: `{bpm}` (60–180), `{key}` (e.g. E♭ minor), `{meter}` (e.g. 7/8).

## Notes for the app

- **Combining:** Drawing one card from 2–4 categories at once (e.g. Mode + Rhythm + Sound + Limit) gives a complete "brief" for a track.
- **Category locking:** Let the user lock a card they like and re-roll the rest.
- **Conflicts:** Some cards contradict each other (e.g. *No drums* + *Use a bossa nova rhythm*). Either tag them as incompatible, or keep it as a deliberate challenge ("make it work").
- **Difficulty / intensity:** Tag cards as gentle, medium or extreme so users can dial in how hard the brief is.
- **Concrete vs. oblique:** Possibly a slider between concrete DAW cues and more poetic, open cues (the Wildcard category).
- **Random values:** Some cards could generate parameters (random BPM, random key, random time signature) instead of fixed text.
- **History:** Save drawn combinations so a user can revisit the brief behind a finished song.
